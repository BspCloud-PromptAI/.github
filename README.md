# BSP Prompt

## Sobre

A BSP Prompt é uma consultoria especializada em Inteligência Artificial Generativa, com foco em soluções estratégicas e produtos baseados em modelos como Claude, AWS Bedrock e Gemini, oferecendo implementação prática para clientes corporativos.

## Meios de Comunicação

### WhatsApp
Comunidade BSP Prompt

### Teams
Meios de comunicação

### Slack
Comunicação rápida

### BSP-System
Sistema de marcação de ponto e marcação de mesa no presencial

## Observações

- Utilize o **WhatsApp** para assuntos gerais da comunidade.
- Utilize o **Teams** para reuniões e comunicados oficiais.
- Utilize o **Slack** para trocas rápidas do dia a dia.
- Utilize o **BSP-System** para marcar ponto e reservar mesa no presencial.
